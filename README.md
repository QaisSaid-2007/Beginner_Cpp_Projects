# Beginner C++ Projects

A collection of beginner-level C++ projects that I built while learning and practicing C++ programming.

## About

This repository contains 9 small C++ projects created to practice the fundamentals of C++ through simple, practical programs.

The projects focus on writing functions, working with arrays, loops, conditions, pointers, user input, and basic problem-solving.

## Projects

| # | Project | Description |
|---|---------|-------------|
| 1 | Console Calculator | A simple calculator for basic arithmetic operations. |
| 2 | Banking System | A simple banking program for checking balance, depositing, and withdrawing money. |
| 3 | Credit Card Validator | Validates credit card numbers using the Luhn algorithm. |
| 4 | Tic-Tac-Toe | A console-based Tic-Tac-Toe game against the computer. |
| 5 | Guessing Game | A simple number guessing game. |
| 6 | Grade Calculator | Calculates grades based on user input. |
| 7 | Hypotenuse Calculator | Calculates the hypotenuse of a right triangle. |
| 8 | Quick Bank | A simple menu-based banking program. |
| 9 | Calculator | A basic C++ calculator project. |
